# detntorch

Research implementations of object-detection networks in PyTorch:

- YOLOv3, YOLOv3-SPP and YOLOv3-tiny
- Faster R-CNN
- RetinaNet

> [!NOTE]
> This is an archived-style research codebase originally written in 2020.
> The dependency baseline was renewed in 2026, but pretrained checkpoints and
> training results are not shipped with the repository.

## Requirements

- Python 3.10–3.14
- PyTorch 2.13 and torchvision 0.28
- A CUDA-capable GPU is recommended for training

Pillow is constrained to 12.3.0 or newer because that release fixes
CVE-2026-54060 in `FontFile.compile()`.

## Installation

Clone the project and create an isolated environment:

```bash
git clone https://github.com/dswanderley/detntorch.git
cd detntorch
python -m venv .venv
```

Activate it on Linux or macOS:

```bash
source .venv/bin/activate
```

Or on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

For CPU-only usage, install all dependencies directly:

```bash
python -m pip install --upgrade pip
python -m pip install --requirement python/requirements.txt
```

For CUDA, first use the command generated by the official
[PyTorch installer](https://pytorch.org/get-started/locally/) for the matching
CUDA version, then install the remaining requirements.

## Data and paths

The scripts expect to run from the `python` directory. Dataset locations and
class names are configured in `python/config/ovarian.data`. Large datasets,
weights, logs and generated predictions are intentionally ignored by Git.

```bash
cd python
```

Before running a command, update the dataset paths in the data configuration
and place any checkpoint under `weights/`.

## Training

```bash
python train_rcnn.py --batch_size 8
python train_retina.py --batch_size 8
python train_yolo.py --model_name yolov3 --batch_size 6
python train_yolo.py --model_name yolov3-tiny --batch_size 8
```

Use `python <script>.py --help` to inspect all parameters. Training creates
TensorBoard events under `logs/`; inspect them with:

```bash
tensorboard --logdir ../logs
```

## Evaluation and detection

Evaluation scripts:

```bash
python test_rcnn.py --weights_path ../weights/model.pth.tar
python test_retina.py --weights_path ../weights/model.pth.tar
python test_yolo.py --model_name yolov3 --weights_path ../weights/model.pth.tar
```

Detection/visualization scripts:

```bash
python detect_rcnn.py --weights_path ../weights/model.pth.tar
python detect_retina.py --weights_path ../weights/model.pth.tar
python detect_yolo.py --model_name yolov3 --weights_path ../weights/model.pth.tar
```

## Project layout

```text
python/
  config/       YOLO and dataset configuration
  models/       Faster R-CNN, RetinaNet and YOLO implementations
  utils/        datasets, transformations, metrics and training utilities
  train_*.py    training entry points
  test_*.py     evaluation entry points
  detect_*.py   detection and visualization entry points
datasets/       local dataset placeholders
logs/           local TensorBoard output
predictions/    generated predictions
weights/        local checkpoints
```
